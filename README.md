# Projeto-PDS
Essa aplicação web permitirá que fãs da Formula 1 acompanhem as corridas em tempo real, com dados detalhados dos pilotos e suas equipes. Utilizando a API OpenF1, a plataforma oferecerá uma experiência interativa, permitindo que usuários estejam sempre informados sobre o campeonato.

## Funcionalidades Planejadas
- **Acompanhamento de corridas em tempo real:** exibição de dados ao vivo das corridas;

- **Calendário das Corridas:** calendário completo da temporada, com detalhes de cada GP, horários e circuitos;

- **Perfil dos Pilotos e Equipes:** informações detalhadas dos pilotos, como número, acrônimo, estatisticas do time e detalhes dos carros.

- **Perfil de Usuário:** informações do time e piloto favoritos do usuário;

- **Classificação do Campeonato:** tabela de pontos para pilotos e construtores atualizada a cada GP;

- **Highlights de corridas passadas:** mostra os melhores momentos das corridas anteriores;

- **Eventos na Pista e Clima:** informa o usuário do que está acontecendo pela pista, como bandeiras, condições climáticas e safety car;

- **Histórico de corridas:** permite que o usuário acesse dados de corridas passadas;

- **Dados de telemetria:** gráficos sobre velocidade máxima, aceleração e frenagem de cada carro;

- **Mapa da Corrida:** gera uma visualização em tempo real da posição dos carros sobre a pista;

- **Previsão de vencedores:** mostrará ao usuário um póssivel pódio do proximo GP.

## Tecnologias 
- **Spring**;
- **CSS, HTML, JavaScript**;
- **PostgreSQL**.
